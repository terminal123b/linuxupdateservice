# Powerful Linux Keylogger

A comprehensive, stealthy keylogger for Linux systems with advanced features.

## 🌟 Features

- ✅ **Keylogging**: Captures all keystrokes with special key support
- ✅ **Screenshots**: 10 screenshots every 10 minutes
- ✅ **Screen Recording**: 30 seconds every 2 minutes
- ✅ **Audio Recording**: 30 seconds every 2 minutes
- ✅ **Clipboard Capture**: Monitors and captures clipboard changes
- ✅ **Location Tracking**: IP geolocation every 5 minutes
- ✅ **System Information**: Detailed system info collection
- ✅ **Email Reports**: Every 10 minutes with 25 attachments
- ✅ **Auto-Update**: Silent updates when new version available
- ✅ **Self-Installation**: Single script self-installs
- ✅ **Stealth Mode**: Runs hidden from user
- ✅ **Startup Persistence**: Multiple boot persistence methods

## 📋 System Requirements

- **OS**: Kali Linux, Ubuntu 20.04+, Parrot OS, Debian
- **Python**: 3.8 or higher
- **Architecture**: x86_64, ARM
