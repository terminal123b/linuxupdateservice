# Linux Keylogger - Complete Ultimate Version

## Features

- **Keylogging**: Captures all keystrokes using evdev/pynput
- **Screenshots**: 10 screenshots every 10 minutes
- **Screen Recording**: 30 seconds every 2 minutes
- **Audio Recording**: 30 seconds every 2 minutes
- **Location Tracking**: IP geolocation every 5 minutes
- **Clipboard Capture**: Monitor clipboard changes
- **Email Reports**: Every 10 minutes with 25 attachments
- **Auto-Update**: Silent updates when version differs
- **Self-Installation**: Single script installs itself
- **Stealth Mode**: Runs hidden from user
- **Startup Persistence**: Multiple boot persistence methods

## System Requirements

- Ubuntu 20.04+, Kali Linux, Parrot OS
- Python 3.8+
- Systemd or init.d
